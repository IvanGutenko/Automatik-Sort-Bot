# Automatik Sort Bot

Telegram-бот для классификации товарных публикаций и распределения по категориям и каналам. Настройки доступны администратору в Telegram.

**Стек:** Python · aiogram · PostgreSQL · asyncpg · HTTPX · AI vision · Docker.

## Возможности

- Анализ текста и фотографий товара, определение категории и уверенности.
- Автоматическая маршрутизация и ручной разбор спорных товаров.
- Несколько каналов и категорий, индивидуальные правила и управление провайдерами AI.
- Раздельная оценка дополнительных категорий; правила для комплектов и отдельных вещей.
- Сохранение состояния и результатов доставки в PostgreSQL.

## Структура и запуск

`app/` содержит обработчики, классификацию, маршрутизацию, доставку и слой БД; `tests/` — существующие проверки.

```bash
cp .env.example .env
# Заполнить токен своего бота, ADMIN_IDS, ключ AI и параметры БД.
docker compose -f compose.yml up -d --build
```

Категории, каналы и правила подключаются через `/admin`. Для нового экземпляра нужны собственные токены и права бота в выбранных каналах. Рабочая база и клиентские публикации в репозиторий не входят.
